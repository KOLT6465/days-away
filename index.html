📅 macOS menu bar utility

Days Away

A tiny countdown for the dates that matter. Add an event, choose a date, and keep the days away visible from your Mac menu bar.

What it does

  • Shows upcoming events in a compact native macOS popover.
  • Makes the number of days the visual focus.
  • Stores events locally on your Mac.
  • Uses optional local notifications for important countdown moments.

What it does not do

  • No accounts.
  • No cloud service.
  • No analytics.
  • No external API calls.
